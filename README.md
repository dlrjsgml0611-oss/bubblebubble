# 🫧 Bubble Bubble

초강력 인터랙티브 모션 그래픽! 7가지 모드와 파워업 시스템, 점수와 콤보까지!

## ✨ 주요 기능

### 🎮 7가지 게임 모드

1. **🫧 노말 모드** (`1`) - 기본 모드, 버블들이 마우스를 따라다님
2. **🎆 폭죽 모드** (`2`) - 클릭하면 화려한 폭죽이 터짐
3. **🌍 중력 모드** (`3`) - 현실적인 중력 물리 시뮬레이션
4. **⚡ 반발 모드** (`4`) - 마우스가 버블을 밀어냄
5. **🌀 카오스 모드** (`5`) - 무작위로 폭발하는 미친 모드
6. **🕳️ 블랙홀 모드** (`6`) - 클릭해서 블랙홀 생성, 버블을 빨아들임
7. **🌈 레인보우 모드** (`7`) - 모든 것이 무지개 색으로!

### 🎮 조작법

#### 모드 전환 (숫자)
- `1-7` - 각 모드로 전환

#### 특수 기능
- `스페이스바` - 메가 폭발! 10개의 폭죽이 연속으로!
- `T` - 파티클 트레일 효과 ON/OFF
- `M` - 버블 20개 추가
- `E` - 모든 버블 폭발 (100점!)
- `R` - 리셋

# 🌤️ Seoul Weather Graphics

서울의 실시간 날씨를 시각적으로 표현하는 라이브 모션 그래픽!

## ✨ 날씨별 비주얼 효과

### ☀️ 맑음 (Clear)
- 밝은 파란 하늘 그라디언트
- 태양 + 광선 효과
- 반짝이는 별 (밤)
- 온도에 따라 하늘 색상 변화

### ☁️ 흐림 (Clouds)
- 움직이는 구름 레이어
- 부드러운 회색 톤
- 바람 속도에 따라 구름 이동 속도 변화

### 🌧️ 비 (Rain/Drizzle)
- 200개의 빗방울 파티클
- 바람 방향에 따라 기울어짐
- 어두운 하늘
- 이슬비는 100개의 부드러운 파티클

### ⛈️ 뇌우 (Thunderstorm)
- 300개의 강한 빗방울
- 랜덤 번개 효과
- 번쩍이는 화면 플래시
- 가지치는 번개 시각화

### ❄️ 눈 (Snow)
- 150개의 눈송이 파티클
- 6각형 눈송이 디자인
- 부드럽게 회전하며 떨어짐
- 차가운 파란색 톤

### 🌫️ 안개/먼지 (Mist/Fog/Haze/Dust)
- 100개의 먼지 파티클
- 부드러운 움직임
- 흐릿한 분위기
- 낮은 가시성 효과

### 🌡️ 온도별 색상

- **매우 추움** (< 0°C): 진한 파란색
- **추움** (0-10°C): 시원한 파란색
- **시원함** (10-20°C): 맑은 하늘색
- **따뜻함** (20-28°C): 밝은 파란색
- **더움** (> 28°C): 따뜻한 주황색 톤

## 🎮 조작법

- **마우스 클릭**: 즉시 날씨 업데이트
- **스페이스바**: 랜덤 날씨 데모
- **R 키**: 실시간 날씨 새로고침
- **버튼**: UI 컨트롤 사용

## 📊 실시간 정보 표시

- 현재 날씨 상태 (아이콘 + 한글)
- 온도 (°C)
- 풍속 (m/s)
- 습도 (%)
- 자동 업데이트 (10분마다)

## 🔧 API 설정 (선택사항)

실제 서울 날씨를 보려면:

1. [OpenWeatherMap](https://openweathermap.org/api)에서 무료 API 키 발급
2. `weather.js` 파일에서 API_KEY 변경:
```javascript
const API_KEY = 'your-api-key-here';
```

**참고**: API 키 없이도 데모 모드로 모든 날씨를 체험할 수 있습니다!

# 🚀 실행 방법

## 방법 1: 직접 실행
1. `index.html` 또는 `weather.html` 파일을 브라우저로 열기
2. 즐기기!

## 방법 2: 로컬 서버 (권장)
```bash
# Python
python -m http.server 8000

# 브라우저에서
http://localhost:8000/index.html      # 버블 게임
http://localhost:8000/weather.html    # 날씨 그래픽
```

## 방법 3: Node.js
```bash
npx http-server
```
