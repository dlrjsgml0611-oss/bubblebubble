# 🫧 Bubble Bubble - Enhanced Interactive Motion Graphics

p5.js로 만든 초강력 인터랙티브 모션 그래픽 프로젝트! 7가지 모드와 파워업 시스템, 점수와 콤보까지!

## ✨ 주요 기능

### 🎮 7가지 게임 모드

1. **🫧 노말 모드** (`1`) - 기본 모드, 버블들이 마우스를 따라다님
2. **🎆 폭죽 모드** (`2`) - 클릭하면 화려한 폭죽이 터짐
3. **🌍 중력 모드** (`3`) - 현실적인 중력 물리 시뮬레이션
4. **⚡ 반발 모드** (`4`) - 마우스가 버블을 밀어냄
5. **🌀 카오스 모드** (`5`) - 무작위로 폭발하는 미친 모드
6. **🕳️ 블랙홀 모드** (`6`) - 클릭해서 블랙홀 생성, 버블을 빨아들임
7. **🌈 레인보우 모드** (`7`) - 모든 것이 무지개 색으로!

### 💥 인터랙티브 기능

- **마우스 인터랙션**: 버블들이 마우스를 따라다니거나 도망감
- **클릭 폭발**: 클릭할 때마다 화려한 파티클 폭발
- **드래그 트레일**: 드래그하면 파티클 궤적 생성
- **버블 충돌**: 버블끼리 부딪히면 튕겨남
- **연결선**: 가까운 버블들이 선으로 연결됨

### ✨ 파워업 시스템

랜덤하게 나타나는 4가지 파워업을 버블로 획득하세요:

- **🧲 자석**: 5초간 모든 버블이 마우스를 따라옴
- **🌈 레인보우**: 5초간 초고속 색상 변화
- **💣 폭발**: 화면의 모든 버블이 한번에 폭발
- **✨ 증식**: 모든 버블이 2배로 증가

### 🎯 게임 요소

- **점수 시스템**: 행동마다 점수 획득
- **콤보 시스템**: 빠르게 클릭하면 콤보 증가
- **100개의 반짝이는 별**: 배경에 살아있는 우주
- **동적 웨이브 배경**: 모드에 따라 변하는 웨이브
- **펄스 효과**: 버블이 살아 숨쉬듯 움직임

## 🎮 조작법

### 🖱️ 마우스
- **이동**: 버블이 따라옵니다
- **클릭**: 폭발 효과 생성
- **드래그**: 파티클 트레일 생성

### ⌨️ 키보드

#### 모드 전환 (숫자)
- `1` - 노말 모드
- `2` - 폭죽 모드
- `3` - 중력 모드
- `4` - 반발 모드
- `5` - 카오스 모드
- `6` - 블랙홀 모드
- `7` - 레인보우 모드

#### 특수 기능
- `스페이스바` - 메가 폭발! 10개의 폭죽이 연속으로!
- `T` - 파티클 트레일 효과 ON/OFF
- `M` - 버블 20개 추가
- `E` - 모든 버블 폭발 (100점!)
- `R` - 리셋

## 🚀 실행 방법

### 방법 1: 직접 실행
1. `index.html` 파일을 브라우저로 열기
2. 즐기기!

### 방법 2: 로컬 서버 (권장)
```bash
# Python이 설치되어 있다면
python -m http.server 8000
# 또는
python3 -m http.server 8000
```
브라우저에서 `http://localhost:8000` 접속

### 방법 3: Node.js
```bash
npx http-server
```

## 🛠️ 기술 스택

- **[p5.js](https://p5js.org/)** - 크리에이티브 코딩 라이브러리
- **HTML5 Canvas** - 고성능 2D 렌더링
- **JavaScript ES6+** - 최신 자바스크립트 기능 활용
- **Object-Oriented Programming** - 깔끔한 클래스 기반 구조

## 🎨 코드 구조

### 주요 클래스

- **`Bubble`** - 메인 버블 객체 (물리, 렌더링, 인터랙션)
- **`Particle`** - 파티클 효과 (폭발, 트레일)
- **`Star`** - 배경 별 효과 (반짝임)
- **`PowerUp`** - 파워업 아이템
- **`BlackHole`** - 블랙홀 (회전하는 소용돌이)

### 주요 기능

- **`draw()`** - 메인 렌더링 루프 (60 FPS)
- **`drawWaveBackground()`** - 동적 웨이브 배경
- **`drawUI()`** - 게임 UI (모드, 점수, 콤보)
- **`createExplosion()`** - 폭발 효과 생성
- **`createFirework()`** - 폭죽 효과 생성
- **`collectPowerUp()`** - 파워업 획득 처리
