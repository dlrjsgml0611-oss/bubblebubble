# 🫧 Bubble Bubble - Interactive Motion Graphics

p5.js로 만든 인터랙티브 모션 그래픽 프로젝트입니다.

## ✨ 기능

- 🎨 **인터랙티브 버블**: 마우스를 따라다니는 컬러풀한 버블들
- 💥 **클릭 폭발 효과**: 클릭하면 파티클이 폭발합니다
- 🌊 **웨이브 배경**: 부드럽게 움직이는 웨이브 배경
- 🔗 **버블 연결**: 가까운 버블들이 선으로 연결됩니다
- 🎭 **자연스러운 물리**: 버블들이 서로 밀어내고 끌어당깁니다

## 🎮 사용법

- **마우스 이동**: 버블들이 마우스를 따라옵니다
- **클릭**: 폭발 효과와 함께 새로운 버블 생성
- **드래그**: 파티클 트레일 생성
- **R 키**: 리셋

## 🚀 실행 방법

1. `index.html` 파일을 브라우저로 열기
2. 또는 로컬 서버로 실행:
   ```bash
   # Python이 설치되어 있다면
   python -m http.server 8000
   # 또는
   python3 -m http.server 8000
   ```
3. 브라우저에서 `http://localhost:8000` 접속

## 🛠️ 기술 스택

- [p5.js](https://p5js.org/) - 크리에이티브 코딩 라이브러리
- HTML5 Canvas
- JavaScript ES6+

## 🎨 특징

- HSB 색상 모드로 생생한 컬러
- 부드러운 애니메이션과 트랜지션
- 반응형 디자인 (브라우저 크기에 맞춰 조절)
- 60 FPS 타겟으로 부드러운 움직임
